# Water Level Indicator Using NOT Gates

A simple and cost-effective electronic water level monitoring system designed using **NOT gates (IC 7404), BC547 transistors, LEDs, resistors, and a buzzer**.

The system detects different water levels and provides visual indications through LEDs. An audible buzzer is activated when the water reaches the overflow level. The project demonstrates the practical application of **digital logic gates and transistor switching** for water level monitoring.

## Key Features

* Detects multiple water levels
* LED-based visual indication
* Buzzer alert for overflow
* Simple and low-cost circuit
* Built using basic digital electronics components
* Useful for learning digital logic and transistor switching
